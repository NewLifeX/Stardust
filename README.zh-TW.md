星塵（Stardust）是分散式服務平台，提供節點管理、註冊中心、設定中心、APM 監控、發佈中心與遠端命令，支撐大規模邊緣節點維運。

## 安裝

```bash
dotnet add package NewLife.Stardust
```

## 快速開始

```csharp
var client = new StarClient("http://star.newlifex.com:6600") { AppId = "app" };
client.Start();
```

## 核心特性

- 日誌、鏈路追蹤與執行診斷完善
- 長期生產驗證，穩定可靠
- 外掛化與可擴充架構，便於二次開發
