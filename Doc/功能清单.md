- **FIX-2（必改）移动端代理启动失败：NewLife.Core 的 Host 静态构造在 Android/iOS 调用 Console.CancelKeyPress 抛 PlatformNotSupportedException。**
  - 是什么问题：移动端启动 `MobileAgent` → `new MobileStarClient` → `ClientBase` → `MemoryCache` → `TimerX` → `Host` 静态构造，在 Android/iOS 上调用 `Console.CancelKeyPress` 抛 `PlatformNotSupportedException`，导致代理初始化失败。
  - 有什么危害：Android/iOS 代理无法登录与心跳，移动节点不可用；CI 冒烟必然失败。
  - 怎么修改：在 NewLife.Core 的 `Host` 静态构造中对 Android/iOS 跳过 `Console.CancelKeyPress` 与不支持的信号注册；升级依赖后移除 `build-mobile.yml` 冒烟步骤的 `continue-on-error`。
  - 修改后的遗憾：需发布 NewLife.Core 新版本；旧版本依赖的移动端仍不可用。
  - 触发路径：移动端启动时创建 `MobileStarClient`（所有 Android/iOS 设备）。
